# Project organisation and history

The active directory is `Occupational-Fitness-Platform`. The Python package is `occupational_fitness_rag`, distribution name `occupational-fitness-platform`, and CLI `fitness-rag`. Configuration and deliverable manifests use project-relative paths.

The supplied guideline, ten input notes and original field labels remain source assets. Current rules are maintained in `configs/rules/`, source locations in `configs/source_anchors.json`, and validated exchange examples in `examples/contracts/`. Superseded workflow documents and draft contracts have been removed from the active project.

Historical code, superseded outputs, migration records and original non-English material are preserved outside the active project under `E:/code/useless can delete/occupational_fitness_legacy/`. The project owner decides whether to delete those archives.

Directory migration repaired the editable package and command entry points. Ollama weights remain in their original model store. The former session directory may retain editor-generated settings while the editor holds it open; use the new directory for development.

English localisation changes labels, documentation and generated review wording. It does not translate source evidence or alter rule predicates. Previous output bundles remain archived, and English outputs are generated as new runs.
