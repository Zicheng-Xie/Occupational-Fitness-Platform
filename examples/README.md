# Examples

`contracts/syn_m2_009/` contains generated v1.1 structured facts, rule result, evidence pack and doctor-review draft for the original hearing case. Use these for the current multi-module API.

The other JSON/JSONL files and `run_synthetic_demo.py` preserve the v0.2 single-category retrieval contract for compatibility experiments. Its synthetic snippets are not guideline evidence and that demo does not implement a complete fitness assessment.

Run the current complete demo with `fitness-rag demo`.
