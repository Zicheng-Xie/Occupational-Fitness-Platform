# Gold extraction fixtures

`workflow_expectations.json` adds 23 authored engineering regression scenarios over original and separately generated synthetic inputs. These are development expectations, not held-out clinician labels. See `docs/validation.md` for interpretation.

`structured_cases.jsonl` is a manually curated extraction target for the ten supplied `SYN-M2-*` nurse-note fixtures.

Important boundaries:

- It records only facts explicitly supported by the supplied notes.
- It is **not** a gold standard for medical fitness outcome.
- It does **not** encode Austroads thresholds or final Fit/Unfit labels.
- Clinical rule outputs must be generated by the separate deterministic rule engine using a reviewed rulebook.

## Coverage carried forward from the stage-one fixtures

- Supplied cases `SYN-M2-001` to `SYN-M2-010` exercise hypertension-only
  cardiovascular scope, vision and hearing, including missing reports and
  out-of-scope MI/PCI/symptom escalation.
- Authored extension scenarios cover normal, abnormal, missing and boundary
  behaviour for blackout and diabetes, including 5/10-year blackout intervals,
  the 6-week severe-hypoglycaemia interval and 3-month monitoring records.
- An explicit normal summary is accepted only by the dedicated prototype
  screening rules; it must not silently supply numeric measurements.
- Overall outcome stores the rulebook-defined highest-priority result. Module
  assessments, evaluated rules and missing fields retain the underlying facts.

The historical `expected_results/*.json` files used schema 1.0.0 and a single
`review_path`. Current expectations use schema 1.2.0 and distinguish
`rag_review`, `missing_information` and `human_review`; do not copy the legacy
JSON over generated current artifacts.
