# Guideline knowledge base

`raw/ap_g56_22.pdf` is the original supplied publication, preserved byte for byte. `configs/source_anchors.json` defines 28 identified evidence regions with PDF pages, printed pages and bounding boxes, distinguishing commercial table columns from shared guidance.

`processed/source_catalogue.json` and `processed/knowledge_units.json` are generated by `fitness-rag build-knowledge`. Loading verifies the PDF and regional quotations. `indexes/chroma/` is a rebuildable guideline vector cache; patient notes are not indexed there.

A guideline update requires review of the new publication, applicability, source regions and regression expectations. The implemented five-module criteria do not automate the entire guideline.
