# Complex-note diagnostic runs

Open `index.html` for the current comparison and `summary.json` for computed metrics.

- `baseline`: all ten original mixed notes, before this repair.
- `original_complete`: all ten original mixed notes on the final code.
- `validation_complete`: the ten new positive/uncertain notes on the final code.
- Other run folders are retained development attempts, including interrupted runs. They are not the final acceptance collection.
- `pytest.xml`: the final regression test result.
- `bundle_verification.json`: replay and provenance verification of the three selected collections.

All material is synthetic engineering validation. Scores are not independent clinical accuracy estimates.
